# Skill: timetable-import

把课表变成 data/courses.json 里的结构化课程。解析器已实现：`src/timetable_import.py`，
入口脚本：`scripts/import_timetable.py`（默认预览，加 `--apply` 才写入，写入前自动备份 courses.json）。

## 支持的输入
- **文字（.txt）**：一行一门课，写法可混用，例如
  `高等数学 周一 第1-2节 1-17周(单) 教三301 王老师 带:课本、习题册`
  也接受 OCR 后的文字（图片先转文字，见下）。
- **CSV（.csv）**：表头可用中文：课程名/星期/节次/周次/地点/教师/携带物品/校区。
- **Excel（.xlsx）**：第一张表、第一行表头，列名同 CSV。`.xls` 老格式请先另存为 .xlsx/csv。
- **JSON（.json）**：课程对象数组，字段可中文可英文，会统一校验和补全。

## 解析规则（确定性代码，不靠模型猜）
- 周次统一转 `weeks.mode`：`1-17周(单)`→odd、`2-18周(双)`→even、`1-16周`→range、`第1,3,5周`→list、`全学期`→all
- 只有节次时，用 term.json 的 `sectionTimes` 换算出起止时间；给了明确时间（如 19:00-20:40）则以明确时间为准
- 地点拆成 building + room（教三301 → 教三 / 301）；“线上”记为 room=线上
- **绝不猜测**：教师、教室、周次、时间缺失或识别不了的，一律写入 `_issues` 标“待确认”，预览时逐条展示给用户

## 图片课表的工作流
图片 OCR 不在解析器内（保持解析器纯标准库、可测试）：
1. 智能体用视觉能力把课表图片读成“一行一门课”的文字
2. 把文字存成 .txt，走上面的文字导入流程
3. 预览给用户确认（重点核对 `_issues`），确认后 `--apply`

## 导入流程（不可跳步）
`import_timetable.py 课表文件` 预览 → 用户确认/修正待确认项 → `--apply` 写入（自动去重：课程名+星期+节次+周次相同视为重复，自动跳过）
